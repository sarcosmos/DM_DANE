Encuesta EDID 2024 - DANE

Sistema de Minería de Datos

Transformando datos públicos en conocimiento estratégico para analizar el funcionamiento institucional, el desempeño administrativo y el ambiente organizacional en las gobernaciones del país.

Objetivo general

Análisis avanzado de datos institucionales

Esta aplicación web integra visualización, minería de datos e inteligencia analítica para convertir información estadística oficial en conocimiento útil.

Dataset utilizado

Encuesta sobre Ambiente y Desempeño Institucional Departamental

El proyecto utiliza datos de la EDID 2024, con miles de registros, más de 200 variables y mediciones regionales, administrativas, categóricas, ordinales y numéricas.

Metodología

SEMMA

El proceso contempla selección de variables, exploración estadística y visual, limpieza, transformación y preparación de los datos para su análisis.

Python Flask Power BI Orange Data Mining Apache Spark
Nivel 1

Conocimiento Evidente

Dashboards analíticos para visualizar indicadores institucionales, comparaciones regionales, distribuciones estadísticas, tendencias administrativas y comportamientos organizacionales.

Conclusiones

  • El análisis descriptivo permitió identificar patrones visibles relacionados con satisfacción laboral, desempeño institucional y transformación digital.
  • Los resultados evidenciaron niveles altos de satisfacción laboral, con promedios superiores a 4 puntos en la mayoría de regiones.
  • El nivel tecnológico predominante fue intermedio, lo que indica el uso de herramientas tecnológicas de complejidad moderada.
  • El grupo profesional representó la mayor proporción de participantes dentro de la muestra analizada.
  • El dashboard interactivo facilitó la exploración visual y transformó información estadística en conocimiento evidente.
Nivel 2

Conocimiento Multidimensional

Modelo estrella para organizar la información analítica mediante tablas de hechos, dimensiones, consultas analíticas e indicadores multidimensionales.

Conclusiones

  • El modelo estrella organizó la información en una tabla de hechos y dimensiones de región, demografía, percepción y seguridad.
  • Las consultas DAX permitieron generar indicadores analíticos relevantes para el estudio.
  • La percepción promedio fue de 3.73 y el índice general de 3.71, mostrando una tendencia moderadamente positiva.
  • El índice de satisfacción fue de 2.08, señalando percepciones menos favorables en algunas variables de seguridad y servicios.
  • Se identificaron perfiles demográficos diferenciados, patrones de percepción, segmentación regional y 326 registros asociados a percepción positiva.
Nivel 3

Conocimiento Oculto

Aplicación de clustering para descubrir grupos de comportamiento similares, tendencias institucionales, relaciones entre variables y segmentaciones organizacionales.

Conclusiones

  • Se implementó exitosamente un proceso de minería de datos utilizando Orange Data Mining.
  • La preparación incluyó transformación de variables categóricas y normalización de variables numéricas.
  • El algoritmo k-Means permitió identificar tres segmentos principales dentro del dataset.
  • La aplicación de PCA facilitó la representación visual de los clusters generados.
  • El Scatter Plot evidenció separación clara entre grupos, indicando patrones ocultos en los datos.
Nivel 4

Conocimiento Profundo

Procesamiento distribuido con Apache Spark para entrenamiento de modelos, evaluación de métricas y análisis avanzado de grandes volúmenes de datos.
